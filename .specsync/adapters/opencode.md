# SpecSync — OpenCode Instructions

This project uses **SpecSync** to keep all software design artifacts and source code always
in sync using a team of specialized AI skills.

---

## Activation

Only activate SpecSync when the user's message **explicitly starts with `/ss`**.
Do not activate for general feature requests or any message that does not begin with `/ss`.

---

## Procedure

Skills are auto-discovered from `.agents/skills/`. When `/ss` is triggered, read
`.agents/skills/specsync/SKILL.md` and follow the workflow defined there.
